# LawPDF 0.2.91 — A simpler markup cursor

Draft release notes; publication and platform availability are still pending.

- The highlighter cursor shows the selected color, with the marker tip at the selection point. On Windows this is a native cursor.
- Click the active color or underline a second time to return to the arrow selection tool.
- Selecting text with the arrow automatically copies it to the clipboard in Original and Review views. Cross-page Original selections wait for the required text before copying.

This version also includes the changes listed in the [0.2.90 draft notes](v0.2.90.md).
