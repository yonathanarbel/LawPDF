# LawPDF 0.2.89 — A more readable Review

Created by Professor Yonathan Arbel. LawPDF is a free, open-source reader for legal scholarship.

## What's new

- **A slower Review reveal.** On the first switch to Review, words lift from the original page and settle into reading order over about 3.2 seconds. Visible words leave in sequence and each has time to travel. Click, scroll, or press a key to skip it; Reduce motion turns it off.
- **Read with the keyboard.** Page Up and Down, Space, arrows, J/K, Home and End move through a document. Ctrl/Cmd+G opens the page field; Ctrl/Cmd+0, 1, and 2 choose fit page, actual size, and fit width. Press `?` for shortcuts.
- **Select across pages.** Drag across page boundaries, double-click a word, triple-click a paragraph, or extend a selection with Shift+click. Paragraph boundaries can be approximate when Review has no unambiguous source mapping.
- **Resume reading.** Recent documents remember position, zoom, and view; an undoable notice identifies a restored position. An optional setting reopens a prior tab session. Tabs can be reordered, closed with middle-click, or managed from their context menu.
- **Navigate legal materials.** PDF links and bookmarks work in the original view, with back/forward history for supported jumps. After Review prepares an index, supported footnote markers can show a preview; unambiguous `supra note` and a limited set of `Id.` references can link to earlier notes.
- **Work with quotations and notes.** Copy a selection with a reviewable journal-article citation draft. Review all inferred metadata and supply the journal abbreviation. The Notes panel lists LawPDF annotations and supported read-only marks from other PDF apps; it can export a Markdown digest with reviewable page citations.
- **Make the reader your own.** Choose light or dark window appearance, or follow the system. An optional display tint dims original pages without changing the PDF or print output. System-voice reading can start at a passage and offers speed and follow-along controls.
- **Performance and reliability.** Review layout retains and draws visible content, settled highlights no longer request continuous repaints, page textures have a shared memory budget, and slow page renders can be cached in the background. Large eligible PDFs can show a temporary read-only first-page preview while their editable recovery snapshot is prepared. Failed opening and annotation saves have retry actions.
- This release also includes the previously prepared **Windows print controls** and the newer asynchronous **Find** interface.

## Beta limits and installation

LawPDF is a public beta. Review reconstruction, detected citation metadata, paragraph boundaries, footnote references, and annotation extraction can be incomplete; check important quotations and citations against the original. Some animation, selection, accessibility, large-document, and speech behavior still needs broader real-world testing. Imported third-party marks are read-only and unsupported annotation types may be omitted.

Windows and macOS direct downloads can receive signed in-app updates after publication. Linux updates are manual. The Windows installer is not publisher-signed; the macOS app is ad hoc signed and not notarized. GitHub publication does not update the Microsoft Store edition. See `RELEASE-VERIFICATION.json` for the published packages' hashes and build evidence.
