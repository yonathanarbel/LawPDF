## LawPDF 0.2.37 — Mac printing

**Created by Professor Yonathan Arbel.** A free, open-source PDF reader for legal
scholarship, close reading, footnotes, and annotation.

### What's new

- On Mac, press **Command-P** or choose **File → Print…** to open the standard
  macOS print dialog. Print is also available in the export menu.
- Choose a printer, page range, copies, or **PDF → Save as PDF**. Printing uses
  the original page layout and includes your current annotations, including
  unsaved edits, without changing the source PDF.
- The print sheet keeps LawPDF responsive. Finish or cancel printing before
  quitting the app.

This release retains the reading interface, optional coffee support, Finder
opening, and save-aware closing improvements from 0.2.36. Printing is new on
macOS; this release does not add a Windows print command.

### Download

- [Mac ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.37/LawPDF-macos.zip) — Apple silicon, macOS 13 or later.
- [Windows installer](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.37/LawPDFSetup-x64.exe)
- [Windows portable ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.37/LawPDF-windows-portable-x64.zip)

Close the older app before installing. On Mac, extract the ZIP and replace
LawPDF.app in Applications. On Windows, run the installer or extract the entire
portable ZIP. Keep backups of important PDFs while using this beta.

The direct Windows downloads are not publisher-signed. The Mac app is ad hoc
signed and not notarized; first launch may require
[Apple's per-app approval process](https://support.apple.com/en-us/102445).
Do not disable operating-system security globally.

The [Microsoft Store edition](https://apps.microsoft.com/detail/9MZXSP0C423F)
has a separate release process. This GitHub release does not establish that
version 0.2.37 is available in the Store.

### Verification

Implementation: [PR #26](https://github.com/yonathanarbel/LawPDF/pull/26).
Local Mac tests passed (1,104 tests), including preservation of unsaved
annotations, the source PDF, and its recovery journal during printing, cleanup
of temporary print copies, and rejection of a damaged source snapshot.

On-device checks with a synthetic two-page portrait/landscape document verified
Command-P, File → Print, Cancel, reopening the print dialog, and Save as PDF of
only page 2. The saved output contained exactly that page. Quitting with a print
sheet open preserved the active operation. No physical printer job was sent.

The tagged release and Desktop verification workflows must pass before
publication. `RELEASE-VERIFICATION.json` records their run IDs, source commit,
package identities, and installation of the exact Windows installer on a clean
hosted machine. Product/file/runtime versions, packaged executable hash, Start
Menu targets, and required native/context runtime must all pass. Hosted checks
do not establish testing on the owner's own Windows PC.

Package byte sizes, SHA-256 hashes, GitHub build provenance, and the detached
Ed25519 update-manifest signature are verified before publication. Downloads
include `SHA256SUMS.txt`, `UPDATE-MANIFEST.json`, and `UPDATE-MANIFEST.sig`.

### Beta status and privacy

Full VoiceOver/NVDA workflows, broad reading fidelity, large-document performance,
cloud-sync conflicts, field reliability, and interrupted automatic updates remain
under evaluation. Use the manual downloads above. Verify reconstructed quotations
and citations against the original PDF. The native PDF worker contains crashes
but is not an operating-system security sandbox.

Read the [privacy guide](https://github.com/yonathanarbel/LawPDF/blob/main/docs/PRIVACY.md)
before enabling network-backed AI features. Optional support is processed by Buy
Me a Coffee and its payment providers in your browser; LawPDF does not collect
payment details. [Report problems](https://github.com/yonathanarbel/LawPDF/issues)
without uploading confidential documents or private research.
