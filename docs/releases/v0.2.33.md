## LawPDF 0.2.33 — public beta for Windows and Mac

**Created by Professor Yonathan Arbel.** A free, open-source PDF reader built for
legal scholarship, close reading, footnotes, and annotation.

**“The world's best PDF app for lawyers and law professors.”** This expresses the
creator's ambition, not an independently tested ranking.

### What is fixed

- **Open directly from Finder:** PDFs now open when LawPDF is completely closed,
  including multiple selected files and filenames with spaces or accented characters.
- **Close predictably:** Command-W closes the current tab; when the reader is empty,
  Command-W closes its window.
- **Quit safely on Mac:** Command-Q, the Quit menu, and native quit requests now use
  the same save checks as closing the window. Pending saves finish first. A failed
  save keeps the document open and offers Save, Don't save, or Cancel.

The intermittent historical close-error dialog was not reproduced during this
validation. The confirmed startup and close-handling defects above are fixed;
no claim is made that every possible cause of a close error has been identified.

### Download

- [Windows installer](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.33/LawPDFSetup-x64.exe)
- [Windows portable ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.33/LawPDF-windows-portable-x64.zip)
- [Mac ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.33/LawPDF-macos.zip) — Apple silicon, macOS 13 or later.

Close the older app before installing. On Mac, extract the ZIP and replace
LawPDF.app in Applications. On Windows, run the installer or extract the entire
portable ZIP. Keep backups of important PDFs while using this beta.

Windows packages are not publisher-signed. The Mac app is ad hoc signed and not
notarized; first launch may require [Apple's per-app approval process](https://support.apple.com/en-us/102445).
Do not disable operating-system security globally.

### Verification

Source commit: `e61c5da3e963b6c7c1c9e63143aa3f4285248dbc`, from
[PR #22](https://github.com/yonathanarbel/LawPDF/pull/22).

- [Tagged release checks](https://github.com/yonathanarbel/LawPDF/actions/runs/35793962724)
  cover 1,079 optimized Mac tests, 1,078 optimized Windows tests, both packages,
  and installation of the exact Windows installer on a clean hosted machine.
- [Desktop verification](https://github.com/yonathanarbel/LawPDF/actions/runs/35793949997)
  covers production/development suites, Markdown checks, and the dependency audit.
- `RELEASE-VERIFICATION.json` retains package identities and the Windows installation
  evidence, including product/file versions, executable hash, Start Menu target,
  and successful required native/context runtime checks. This is hosted Windows
  evidence, not testing on the owner's own Windows hardware.

Local installed-app tests covered repeated Finder cold launches, simultaneous
opening of two documents, Unicode filenames, repeated opening without duplicate
tabs, and closing tabs and windows. Quitting immediately after a text-box edit
preserved the exact annotation after reopening and independent PDF inspection.
A deliberately read-only test file confirmed that Quit, failed Save, Cancel, and
Command-W preserve unsaved edits until the user explicitly discards them.
The original PDF remained unchanged. No new LawPDF crash report appeared.

Package sizes, SHA-256 hashes, GitHub build provenance, and the detached Ed25519
update-manifest signature are checked before publication. The downloads include
`SHA256SUMS.txt`, `UPDATE-MANIFEST.json`, and `UPDATE-MANIFEST.sig`.

### Beta status and privacy

Full VoiceOver/NVDA workflows, broad reading fidelity, large-document performance,
cloud-sync conflicts, field reliability, and interrupted automatic updates remain
under evaluation. Use the manual downloads above. Verify reconstructed quotations
and citations against the original PDF. The native PDF worker contains crashes
but is not an operating-system security sandbox.

Read the [privacy guide](https://github.com/yonathanarbel/LawPDF/blob/main/docs/PRIVACY.md)
before enabling network-backed AI features. [Report problems](https://github.com/yonathanarbel/LawPDF/issues)
without uploading confidential documents or private research.
