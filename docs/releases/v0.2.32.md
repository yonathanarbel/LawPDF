## LawPDF 0.2.32 — public beta for Windows and Mac

**“The world's best PDF app for lawyers and law professors.”**

Created by **Professor Yonathan Arbel**, LawPDF is a free, open-source PDF reader
built for the footnotes, close reading, and annotation that legal scholarship demands.
The headline expresses the creator's ambition, not an independently tested ranking.

### Read. Annotate. Return to the source.

Review Mode reconstructs reading flow and footnotes in law review articles, while
the original PDF remains available for checking quotations, citations, and layout.
Highlight a case for class, comment on a colleague's draft, search a long article,
or use OCR support with scanned materials.

This release adds automatic annotation saving with recovery journals and revision
checks, undo/redo, shutdown that waits for pending saves, supervised native PDF
processing, accessible page text and named controls, and signed update manifests.

### Download

- **Windows installer:** [LawPDFSetup-x64.exe](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.32/LawPDFSetup-x64.exe)
- **Windows portable:** [LawPDF-windows-portable-x64.zip](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.32/LawPDF-windows-portable-x64.zip) — extract the entire ZIP and run `lawpdf.exe`.
- **Mac:** [LawPDF-macos.zip](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.32/LawPDF-macos.zip) — Apple-silicon Macs, macOS 13 or newer. Extract and drag LawPDF.app to Applications. This build does not support Intel Macs.

Close older versions before installing. Keep backups of important PDFs.
Windows packages are not publisher-signed; Windows may show an unknown-publisher
warning. The Mac app is ad hoc signed and not notarized. Follow
[Apple's per-app approval instructions](https://support.apple.com/en-us/102445)
if macOS blocks first launch; do not disable Gatekeeper globally.

### Beta limitations and privacy

A reported document-opening problem still needs interface reproduction.
Full VoiceOver/NVDA workflows, representative reading fidelity, large-document
performance, cloud-sync conflicts, and field reliability remain under evaluation.
Signed-update replacement, relaunch, and interruption recovery are not yet fully
qualified; use the manual downloads above for this release.
The native PDF worker contains crashes but is not an operating-system security sandbox.

Always verify reconstructed quotations and citations against the original PDF.
See the [privacy guide](https://github.com/yonathanarbel/LawPDF/blob/main/docs/PRIVACY.md)
before enabling network-backed AI features.
[Report problems](https://github.com/yonathanarbel/LawPDF/issues) without uploading
confidential client documents or private research.
