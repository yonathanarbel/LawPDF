# LawPDF 0.2.92 - Cleaner Review and copying

- Review excludes confidently detected recurring diagonal text watermarks before arranging paragraphs.
- Original view uses the same cleaned text for selection, copying, and highlighting, so overlapping watermark letters no longer compete with the passage you select.
- Detection uses appearance, geometry, and recurrence across pages, not a list of watermark phrases. Ambiguous text is retained. The PDF's appearance, printing, and saved contents remain unchanged.
- Existing text and Review caches are refreshed automatically.

This version also includes the colored highlighter cursor, click-again tool deselection, and automatic copying with the arrow from the [0.2.91 notes](v0.2.91.md).

The conservative filter covers large, pale, diagonal text repeated over body text. Image-only, single-page, horizontal, dark, or otherwise ambiguous watermarks may remain. Other Review reconstruction and footnote limitations remain.

Release availability and signing status are recorded with the published packages. An unsigned manual-download beta does not enable authenticated automatic updates.
