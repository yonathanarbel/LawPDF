# LawPDF 0.2.48 — Find the passage

Created by **Professor Yonathan Arbel**. LawPDF is a free, open-source reader for legal scholarship.

- **Ctrl/Cmd+F** opens Find in the masthead and selects the previous query. Type to preview without moving your reading position. Enter goes to the next occurrence, Shift+Enter goes back, and Esc dismisses Find. A count shows your place and indicates wraparound.
- On a PDF, the current occurrence gets a short ink underline. A visible line stays still; an off-screen match lands near the upper third, with an immediate jump for distant pages. Reduced motion removes the transition. Page ticks show where results cluster.
- **All results** opens an optional list of snippets. Original and Review search their respective text; side-by-side search follows the focused pane. OCR snippets without text boxes navigate by page and never invent coordinates. Find marks are temporary; **Annotate** is a separate explicit action.
- Matching runs locally in the background. The current and nearby pages have priority, results stream in with a partial count, and superseded searches cannot move the document. Only visible result rows are laid out.
- The unpublished 0.2.47 test candidate exposed a split-view results-panel issue. This build keeps the list and keyboard navigation available in the focused pane without changing your normal sidebar preference.
- This build also includes the **Windows print preview and print controls** from the unpublished 0.2.46 candidate.

The direct Windows installer is not publisher-signed. The macOS arm64 app is ad hoc signed and not notarized. Linux x86_64 uses a manual update. GitHub publication does not update the Microsoft Store edition.

The signed update manifest authenticates the Windows and Mac packages; SHA-256 checksums and GitHub build attestations cover all four downloads. Consult RELEASE-VERIFICATION.json for the exact artifact and installation evidence after publication.
