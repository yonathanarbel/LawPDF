# LawPDF 0.2.36 — release candidate

This update combines the new reading interface with an optional way to support
LawPDF's development.

- The masthead shows the document's title, authors, and citation.
- The annotation toolbar can be moved over the page.
- Review Mode places footnotes in the reading margin and hides the contents
  sidebar by default; the Original view keeps PDF navigation available.
- A small coffee cup in the top bar opens a friendly, optional support panel.
  It never interrupts reading or limits features.

LawPDF remains available under the MIT license, including commercial use.
