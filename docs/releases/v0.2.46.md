# LawPDF 0.2.46 — Windows print preview

**Created and maintained by Professor Yonathan Arbel.** This public beta adds
the missing Windows print workflow while retaining the existing Mac and Linux
print paths.

## Windows printing

Press **Ctrl+P**, click the visible **Print…** toolbar button, or choose
**Print…** from Export. The ivory-and-teal print window combines a live sheet
preview with printer selection and detailed controls:

- All/current/custom page ranges; odd/even pages and reverse order.
- Copies, collation, simplex and automatic duplex when the printer supports it.
- Letter, Legal, A4 and A3; portrait or landscape; 1, 2 or 4 pages per sheet.
- Fit, shrink-only or actual-size scaling, adjustable margins and grayscale.
- Current annotations, including unsaved edits, with an option to omit markup.
- The Windows system dialog for trays, quality and other device settings.

Printing uses a separate temporary copy and does not rewrite the original PDF.
Filled forms are retained when markup is excluded. Preview rendering respects
print-only and hidden annotation flags. Preparation runs in the background and
can be canceled before handoff to Windows. Once submitted, manage cancellation
in the Windows print queue. A queue receipt does not prove physical paper output.

Windows output is rasterized at a target of 300 DPI, with bounded image sizes.
It is not vector output. Large jobs may take time to prepare, and hardware
margins may crop edge content. See the [printing guide](https://github.com/yonathanarbel/LawPDF/blob/v0.2.46/docs/PRINTING.md).

## Downloads and signing status

- [Windows installer](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.46/LawPDFSetup-x64.exe)
- [Windows portable ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.46/LawPDF-windows-portable-x64.zip)
- [Apple-silicon Mac ZIP](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.46/LawPDF-macos.zip), macOS 13 or later
- [Linux x86_64 archive](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.46/LawPDF-linux-x86_64.tar.gz), Ubuntu 24.04 or compatible modern glibc desktop

Close older LawPDF versions before installing; keep backups of important PDFs.
Direct Windows downloads are **not publisher-signed**. The Mac app remains ad hoc
signed and **not notarized**; use [Apple's per-app approval procedure](https://support.apple.com/en-us/102445)
if needed, not a global Gatekeeper override. The Microsoft Store has a separate
submission/certification process; this release does not establish Store
availability of 0.2.46.

The detached `UPDATE-MANIFEST.sig` authenticates the Windows/Mac updater packages.
This application-level signature does not provide Windows Authenticode signing
or Apple notarization. Linux uses manual installation, verified checksums and
GitHub build provenance.

## Verification and limitations

The release gate requires successful desktop verification and release workflows
for the exact tagged source, package checksums and GitHub provenance, Windows
installation evidence, and the maintainer's detached manifest signature.
The [artifact-specific verification record](https://github.com/yonathanarbel/LawPDF/releases/download/v0.2.46/RELEASE-VERIFICATION.json)
identifies the exact source, workflow runs, package hashes and CI installation
results. The local Windows candidate also passed Ctrl+P screenshot checks at
wide and compact window sizes, native print-rendering checks, simulated printer
output, and print/close regression tests. **No physical printer job was sent
during those tests.** Hosted checks do not establish every printer or driver.

The local 0.2.46 candidate was installed and its product/file versions, Start
Menu target and native/context runtime were verified. That candidate check is
separate from the rebuilt CI release artifacts described in the verification
record.

Accessibility, broad reading fidelity, field reliability, interrupted updates,
and large-document performance remain under evaluation. Verify reconstructed
quotations and citations against the original PDF. Printing stays local; other
optional network features follow the [privacy guide](https://github.com/yonathanarbel/LawPDF/blob/v0.2.46/docs/PRIVACY.md).
