## LawPDF 0.2.43 — Review Mode reveal and citation fixes

**Created by Professor Yonathan Arbel.** A free, open-source PDF reader for legal
scholarship, close reading, footnotes, and annotation.

### What's new

- On the first switch from a printed PDF to Review Mode, words on the current
  page lift into the reading column and footnote margin cards. The reveal lasts
  about a second and plays once per open document. Click, scroll, or press a key
  to end it immediately. Reduced motion, Side by Side, split view, and pages
  without a suitable text layer skip the animation.
- Review Mode follows the current PDF page when switching from the original
  view, instead of opening at the top of the document.
- Reporter abbreviations such as **F.3d**, **F.2d**, **F.4th**, and **S.W.3d**
  retain their series digits in Review Mode and Markdown exports instead of
  turning those digits into false footnote callouts.
- A boundary check prevents a crash when the reveal searches for a source line
  after reaching the last word on the page.

This release also includes the previously merged on-device OCR work for Windows
and macOS, preservation of scanned body text in Review Mode, searchable PDF
copies, and Save As improvements. Mac printing and annotation recovery remain
available.

Close the older app before installing. On Mac, extract the ZIP and replace
LawPDF.app in Applications. On Windows, run the installer or extract the entire
portable ZIP. Keep backups of important PDFs while using this beta.

The Windows downloads are not publisher-signed. The Mac app is ad hoc signed and
not notarized; first launch may require
[Apple's per-app approval process](https://support.apple.com/en-us/102445).
The [Microsoft Store edition](https://apps.microsoft.com/detail/9MZXSP0C423F) has a
separate publication process; this GitHub release does not establish Store
availability of version 0.2.43.

### Verification

Windows and Mac packages are built from the same tagged source. Regression
coverage includes the reveal's word matching and page-boundary handling,
reporter citations, and existing document and annotation behavior. Desktop
verification exercises both normal and development feature sets and audits
dependencies. The release workflow also runs on-device OCR self-tests; a Windows
runner without an installed OCR language records that limitation in its report.

`RELEASE-VERIFICATION.json` records the exact source commit, successful workflow
runs, package hashes and sizes, and installation of the exact Windows installer
on a hosted test machine. Product, file, and runtime versions, the installed
executable hash, Start Menu targets, and required packaged models are checked.
Hosted checks do not establish testing on the owner's own Windows PC.

Package SHA-256 hashes, GitHub build provenance, and the detached Ed25519 update
manifest signature are verified before publication. Downloads include
`SHA256SUMS.txt`, `UPDATE-MANIFEST.json`, and `UPDATE-MANIFEST.sig`.

### Beta status and privacy

Full VoiceOver/NVDA workflows, broad reading fidelity, large-document performance,
cloud-sync conflicts, field reliability, and interrupted automatic updates remain
under evaluation. Verify reconstructed quotations and citations against the
original PDF. The PDF worker contains crashes but is not an operating-system
security sandbox.

Read the [privacy guide](https://github.com/yonathanarbel/LawPDF/blob/main/docs/PRIVACY.md)
before enabling network-backed AI features.
[Report problems](https://github.com/yonathanarbel/LawPDF/issues) without uploading
confidential documents or private research.
